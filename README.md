# Parkdieren oefenen

Nederlandse oefenwebsite voor de kennistoets Parkdieren niveau 2. 78 vragen, korte rondes, antwoorduitleg en herhalen van fouten. Werkt als statische website zonder installatie of backend.

Open `index.html` of publiceer de hoofdmap met GitHub Pages. Voortgang wordt uitsluitend lokaal opgeslagen in de browser. Geen analytics of accounts. Lettertypen worden opgehaald bij Google Fonts; bij ontbreken werkt een lokaal fallback-lettertype.

De oefenvragen zijn geschreven op basis van aangeleverde lespresentaties en werkbladen. Bronverwijzingen staan bij elke vraag. De oorspronkelijke documenten en afbeeldingen worden niet verspreid. De opgegeven Animalis-hoofdstukken waren niet beschikbaar; soortenherkenning op foto's en anatomieplaatjes moeten ook in de originele lesmaterialen worden geoefend.

De website is een oefenhulp, geen volledige reproductie of voorspelling van de toets. De groen gemarkeerde broedtijden zijn weergegeven volgens het antwoordenwerkblad. Bij de tegenstrijdigheid over papegaaiachtigen is het antwoordenwerkblad gevolgd (nestblijvers).
